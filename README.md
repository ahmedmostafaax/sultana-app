## 🌟 أقسام الموقع ومميزاته

1. **الترويسة (Header)**:

   - روابط التنقل: `الخدمات`، `كيف تعمل`، `للشريكات`.
   - زر `انضمي للقائمة`، وأيقونة سلة المشتريات التفاعلية مع عداد الطلبات.

2. **الواجهة الرئيسية (Hero Section - الصفحة 1)**:
   - شارة `قريباً على Google Play و App Store`.
   - العنوان الرئيسي: `كل واحدة سلطانة` والوصف الفاخر.

   - شاشة محاكاة حية للهاتف الذكي تعرض الأقسام الستة الأساسية.

3. **6 خدمات في مكان واحد (الصفحة 1)**:

4. **كيف تعمل؟ (الصفحة 1)**:
   - 3 خطوات مرقمة (اختاري الخدمة، حددي الوقت والخبيرة، ادفعي وتابعي).

5. **عروض اليوم (الصفحة 2)**:
   - كروت العروض الترويجية مع إمكانية نسخ كود الخصم بضغطة واحدة:
     - `خصم %15 - أول حجز لك (FIRST15)`
     - `وفّري %20 - باقة العروس (BRIDE20)`

## 🚀 كيفية رفع المشروع على GitHub (خطوة بخطوة)

اتبع هذه الخطوات البسيطة لرفع مجلد المشروع على حسابك في GitHub:

### 1. أنشئ مستودعاً جديداً (New Repository) على GitHub:
- ادخل على حسابك في [GitHub](https://github.com/new).
- اجعل اسم المستودع: `sultana-app` (أو أي اسم تفضله).
- **لا تضع** علامة صح عند "Add a README file" لأننا جهزنا لك ملف الـ README بالفعل.
- اضغط **Create repository**.

### 2. افتح موجه الأوامر (Terminal / PowerShell) داخل هذا المجلد:
قم بتنفيذ الأوامر التالية بالترتيب:

```bash
# 1. تهيئة المستودع المحلي
git init

# 2. إضافة كافة الملفات
git add .

# 3. حفظ أول Commit
git commit -m "feat: complete sultana platform landing page according to design mockups"

# 4. تحديد الفرع الرئيسي Main
git branch -M main

# 5. ربط المستودع بمستودع GitHub الخاص بك (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/YOUR_USERNAME/sultana-app.git

# 6. الرفع إلى GitHub
git push -u origin main
```

## 🌐 التفعيل المباشر على الإنترنت (GitHub Pages مجاناً)
بعد رفع المشروع، يمكنك نشره للعالم عبر **GitHub Pages** بضغطة زر:
1. اذهب إلى صفحة المستودع على GitHub ثم اضغط على **Settings**.
2. من القائمة الجانبية اختر **Pages**.
3. تحت قسم **Build and deployment**:
   - Source: اختر `Deploy from a branch`.
   - Branch: اختر `main` واضغط **Save**.
4. خلال دقيقة سيظهر لك رابط الموقع المباشر (مثل: `https://YOUR_USERNAME.github.io/sultana-app/`)!

## 💻 التشغيل المحلي السريع (Local Development)

يمكنك تشغيل الموقع بأي طريقة من الطرق التالية:
1. **مباشرة بالمتصفح:** فقط افتح ملف `index.html` في أي متصفح (Chrome, Edge, Safari).
2. **باستخدام Node.js:**
   ```bash
   npm start
   ```
   وسيفتح الموقع تلقائياً على `http://localhost:3000`.
